# 0.3.0

- Add a Files tab (Alt+3) that browses every repository file in a tree and previews the selected file with syntax highlighting.
- Mark working-tree changes in the Files tab: the tree shows each file's status and colors folders that contain changes, and the preview colors added lines and inserts removed lines against HEAD.
- Search file names and file contents from the Files tab filter. Name matches and line matches are listed in separate groups, and choosing a line opens the file at the highlighted match.
- Select lines in the Files preview to copy them, see their blame, and open their line history.
- Move Diff Last to Alt+D and Compare to Alt+M.
- Name comparison endpoints HEAD, Index, and Working Tree, mark uncommitted comparisons with (Uncommitted), and show the full commit title with horizontal scrolling.
- Stop coloring conventional commit prefixes such as feat: and fix: in the Graph.
- Move selection lists one row per mouse wheel notch.
- Reload the Files tree when switching repositories from Workspaces.

Requires Herdr 0.8.0 or later.
