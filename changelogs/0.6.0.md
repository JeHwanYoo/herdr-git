# 0.6.0

- Restore the antialiased Graph curves and commit rules on Herdr 0.9.2 and later. Herdr 0.9.2 removed the pane graphics API that Herdr Git used, so the Graph always showed box-drawing characters and Settings reported "Unavailable in this pane". Herdr Git now sends standard Kitty graphics through the pane and follows Herdr's `kitty_graphics` setting under `[terminal]`, which defaults to `true`.
- Herdr 0.9.0 and 0.9.1 are no longer supported.

Requires Herdr 0.9.2 or later.
