# 0.5.0

- Add a Branches dialog for searching local and remote-tracking branches, with the current branch and branches checked out in worktrees identified in the list. Remote-tracking branches reflect the last fetch.
- Create branches from the Branches dialog, rename local branches, and delete merged local branches after confirmation.
- Protect branches during rename and delete operations: reject branches that changed since the list was loaded, prevent deleting branches checked out in any worktree, and prevent renaming branches checked out in another worktree. Unmerged branches are preserved.

Requires Herdr 0.9.0 or later.
