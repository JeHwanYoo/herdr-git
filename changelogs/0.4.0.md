# 0.4.0

- Add a Settings tab (Alt+,) as the fifth header item.
- Switch the Graph between Kitty graphics and box-drawing characters from Settings. The choice is on by default, is remembered, and leaves the Herdr config alone; Kitty graphics still need `kitty_graphics = true` under `[terminal]` in the Herdr config.
- Check for Herdr Git updates from Settings. The row shows whether the check is running, failed, or found the latest version, and offers to install a newer release.
- Separate Graph commits with a thin rule. With pane graphics the rule is a 1px line; without them a gray underline runs through the blank space of each commit's second line.
- Right-align author names in the Graph under the relative commit time.
- Keep the antialiased Graph visible while a dialog is open. The dialog's area is cut out of the graph image instead of switching the Graph to characters.

Requires Herdr 0.8.0 or later.
