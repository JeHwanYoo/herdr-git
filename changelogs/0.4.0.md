# 0.4.0

- Add a Settings tab (Alt+,) as the fifth header item.
- Turn Kitty graphics on or off from Settings. Herdr Git asks before it writes `[terminal] kitty_graphics` to the Herdr config, keeps a legacy `[experimental]` value in step, and reminds you to restart Herdr.
- Check for Herdr Git updates from Settings. The row shows whether the check is running, failed, or found the latest version, and offers to install a newer release.
- Separate Graph commits with a thin rule. With pane graphics the rule is a 1px line; without them the detail line is underlined.
- Right-align author names in the Graph under the relative commit time.

Requires Herdr 0.8.0 or later.
