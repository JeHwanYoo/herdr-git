# 0.2.2

- Check for newer stable GitHub releases in the background at startup and every 30 minutes.
- Show the installed version and available updates in the top-right corner, with confirmation before installation and a restart action after the build finishes.
- Allow skipping an offered version and remember the choice in the plugin state directory.
- Place Update Herdr Git… at the bottom of Commands and show Update available in its Status column whenever a newer version is detected, including skipped versions.
- Allow manual installation of a skipped release or reinstallation from the latest default branch through Commands.

Requires Herdr 0.8.0 or later.
