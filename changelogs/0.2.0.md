# 0.2.0

- Show target commits and branches in Git operation dialogs, including the Reset mode picker.
- Verify staging and unstaging results and report changes that remain instead of showing a false success.
- Add a discard button beside the stage button for tracked unstaged files. Confirmation is required, and staged changes and untracked files are preserved.
- Add a command to discard all tracked changes back to HEAD, with confirmation and a check that HEAD has not changed.
- Report incomplete discard operations, including filesystem case collisions.

Requires Herdr 0.8.0 or later.
